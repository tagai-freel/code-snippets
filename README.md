# Code Snippets

This repository contains small scripts and snippets for system setup.

## Usage

You can download and execute any script directly using `wget` or `curl`.
Replace `YOUR_GITHUB_USERNAME` with the repository owner's name if hosted on GitHub.

Example to install Docker on Ubuntu:

```bash
wget -qO- https://raw.githubusercontent.com/YOUR_GITHUB_USERNAME/code-snippets/main/scripts/install-docker-ubuntu.sh | bash
```

## Available Scripts

- `scripts/install-docker-ubuntu.sh` - Install Docker Engine on Ubuntu systems.
